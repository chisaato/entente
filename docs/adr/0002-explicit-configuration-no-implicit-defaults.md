# 明确配置，不要隐含默认值

哲学是 upstream-first、声明式、明确配置：没有隐含默认值，宁可麻烦也要看得清楚；一条路由如果看不清楚，就拒绝，而不是猜。不存在默认入口；容器 label 不写入口就不暴露。

## Consequences

三处例外，都因为它们不承载路由或安全决策，或者正是为了堵住隐含配置：

- `entente gen-cert` 可以有默认值（CN / SAN 默认 `invalid`，有效期默认 3650 天）。证书本身不承载路由或安全决策；「明确配置」针对的是路由和安全。
- 路由超时必须显式给出，不沿用 Envoy 隐式的 15s。见 ADR-0017。
- 本地证书路径必须是绝对路径。相对路径会跟着进程工作目录变，等于隐含配置。见 ADR-0018。
